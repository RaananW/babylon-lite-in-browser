How it works

Native ESM from npm to browser

  1. Install the pinned @babylonjs/lite npm dependency.
  2. Build by copying its official browser bundle into the static site.
  3. Map the package name to that file with a browser import map.
  4. Import named Lite APIs from ordinary module scripts.
