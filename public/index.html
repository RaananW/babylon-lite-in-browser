How it works

Native ESM from npm to browser

  1. Choose a pinned npm CDN URL or install @babylonjs/lite locally.
  2. Serve the official browser bundle from the CDN or your own static site.
  3. Map the package name to that file with a browser import map.
  4. Import named Lite APIs from ordinary module scripts.
